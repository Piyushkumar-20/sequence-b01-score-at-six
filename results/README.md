# B1 — Over-6 Output Contract

## Purpose

This file defines the Week 5 integration contract for the B1 — Score at Six
module. It is a **dummy contract file** for interface testing. The values in
`pred_over6.csv` are placeholders and must not be treated as final model
predictions.

## Output

```text
results/pred_over6.csv
```

One row represents one match/innings prediction made from the Over-6
checkpoint.

## Columns

| Column | Meaning | Unit |
|---|---|---|
| `match` | Match identifier corresponding to the source checkpoint | identifier |
| `innings` | Innings number for the prediction | innings number |
| `predicted_score` | Predicted final innings score | runs |
| `low_estimate` | Lower bound of the final prediction range | runs |
| `high_estimate` | Upper bound of the final prediction range | runs |

## Input

The B1 model consumes the Over-6 rows from:

```text
data/processed/checkpoints.csv
```

with:

```text
over_mark = 6
```

The final model uses the B1 feature set defined by the project roadmap.

## Regeneration

The five rows in this file are dummy values created only to validate the
output interface. They are not regenerated by the Week 4 baseline command.

The final `pred_over6.csv` will be regenerated by the finalized B1 prediction
pipeline after the model and uncertainty method have been completed and
validated.

## Assumptions

1. Each row represents exactly one match/innings at the Over-6 checkpoint.
2. `predicted_score`, `low_estimate`, and `high_estimate` are expressed in runs.
3. `low_estimate <= predicted_score <= high_estimate`.
4. Downstream modules should join predictions using `match` and `innings`.
5. The interval methodology is not finalized by this Week 5 contract; these
   dummy bounds do not represent validated coverage.
